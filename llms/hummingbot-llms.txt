# Hummingbot

> Hummingbot is an open source Python framework (Apache-2.0), maintained by the Hummingbot Foundation, for building and running automated high-frequency crypto trading strategies across centralized (CEX) and decentralized (DEX) venues, with 300+ exchange connectors. Developer components include the Hummingbot client (CLI), Gateway (DEX/blockchain REST middleware with a published OpenAPI), the Hummingbot API (FastAPI orchestration server), an async Python client, an official MCP server, and open Agent Skills.

This llms.txt is generated by the API Evangelist enrichment pipeline from the repo's apis.yml and artifacts (no llms.txt is published upstream).

## APIs
- [Hummingbot Gateway](https://hummingbot.org/gateway/): REST middleware standardizing DEX/blockchain access (default :15888); swap, AMM, CLMM, wallet, tokens, pools across Jupiter/Meteora/Orca/Raydium/Uniswap/0x/PancakeSwap.
- [Hummingbot API](https://hummingbot.org/hummingbot-api/): FastAPI server (default :8000) orchestrating bots, accounts, trading, portfolio, and market data; Swagger at /docs; HTTP Basic auth.

## Specs
- [Gateway OpenAPI 3.0.3](openapi/hummingbot-gateway-openapi-original.json): 149 operations across config, wallet, tokens, pools, trading (swap/CLMM), chains, and connectors.
